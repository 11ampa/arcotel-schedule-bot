### <img src="assets/icons/book-open.svg" width="22" height="22" valign="middle" /> о проекте

этот сервис создан для студентов архангельского колледжа телекоммуникаций им. б.л. розинга (акт ф спбгут), чтобы быстро и удобно проверять актуальное расписание пар с официального сайта `arcotel.ru`.

бот полностью избавлен от хардкода: поддерживает произвольное количество людей (для себя, одногруппников, друзей), пагинацию по группам и профилям, компактное управление через редактирование одного сообщения (без засорения чата) и моментальную отправку карточек в любые диалоги через инлайн-режим `@fz_arcotel_bot`.

### <img src="assets/icons/terminal.svg" width="22" height="22" valign="middle" /> архитектура и поток данных

```
telegram клиент
     │
     ├── [@fz_arcotel_bot ...] (инлайн-запрос из любого чата)
     │       └── inline handler → кэш/парсер → InlineQueryResultArticle (карточка расписания)
     │
     └── [/start | /schedule] (личное интерактивное меню)
             └── menu handler (редактирование 1 сообщения, пагинация страниц и профилей)
                     ├── генерация векторной карточки (svg + lucide icons)
                     │       └── rsvg-convert → png-виджет
                     └── async html parser (aiohttp + bs4)
                             └── ttl cache (15 мин) → arcotel.ru
```

### <img src="assets/icons/users.svg" width="22" height="22" valign="middle" /> динамические профили и первичная настройка

* **любое количество людей**: можно добавить профили для себя, светланы, егора, друзей или целых групп.
* **первичный онбординг**: при первом старте бот запускает пошаговый мастер:
  1. выбор или ввод имени профиля.
  2. выбор группы с пагинацией (страницы 1/6) или фильтром по направлениям.
  3. выбор подгруппы (вся группа, 1-я или 2-я подгруппа).
* **управление профилями**: меню `⚙️ Профили` позволяет переключать активный профиль, пролистывать их пагинацией и удалять устаревшие.

### <img src="assets/icons/layers.svg" width="22" height="22" valign="middle" /> пагинация и навигация

* **пагинация групп**: все 47 групп колледжа (испп, исс, кск, оиб, рмт, рпо, сса и др.) разбиты по страницам с кнопками `◀`, `Стр X/Y`, `▶`, а также доступны через фильтр категорий.
* **пагинация профилей**: при большом количестве людей профили листаются постранично.
* **календарная сетка**:
  * быстрые кнопки: `Сегодня`, `Завтра`, `Вся неделя`.
  * точечный выбор дня: `[Пн]`, `[Вт]`, `[Ср]`, `[Чт]`, `[Пт]`, `[Сб]`.
  * перелистывание недель: `◀ Пред. нед.`, `Текущая`, `След. нед. ▶`.
* **фильтрация подгрупп**: переключение `• Все •`, `• 1 п/г •`, `• 2 п/г •` мгновенно пересчитывает расписание для активного профиля.

### <img src="assets/icons/radio.svg" width="22" height="22" valign="middle" /> инлайн-режим (@fz_arcotel_bot)

вызов бота возможен из любого личного чата, группы или канала:

```text
@fz_arcotel_bot
```

* **сразу выдает карточки сохраненных профилей**:
  * `[Имя] — Сегодня ([Группа])`
  * `[Имя] — Завтра ([Группа])`
  * `[Имя] — Вся неделя ([Группа])`
* **поиск по любой группе колледжа**:
  * `@fz_arcotel_bot испп-31` — мгновенно отдает расписание на сегодня и неделю для этой группы.

### <img src="assets/icons/cpu.svg" width="22" height="22" valign="middle" /> рендеринг карточек расписания

вместо стандартного набора смайликов бот использует векторные svg-иконки из библиотеки `lucide` (`assets/icons/`):

* `clock.svg` — время пары и номер звонка.
* `calendar.svg` — день недели и дата.
* `map-pin.svg` — аудитория и корпус.
* `users.svg` — преподаватель.
* `layers.svg` — индикатор подгруппы.

кнопка **«🖼 Карточка»** в интерфейсе генерирует темный графический png-виджет высокого разрешения (через `rsvg-convert`), оформленный в единой цветовой гамме.

### <img src="assets/icons/folder.svg" width="22" height="22" valign="middle" /> структура репозитория

```text
arcotel-schedule-bot/
├── assets/
│   └── icons/                 # векторные svg-иконки (lucide)
├── bot/
│   ├── config.py              # конфигурация путей, окружения и токена
│   ├── storage.py             # асинхронное хранилище профилей (json)
│   ├── parser.py              # парсер сайта arcotel.ru с ttl-кэшем
│   ├── renderer.py            # генератор svg-карточек и рендер в png
│   ├── keyboards.py           # inline-клавиатуры с пагинацией
│   ├── handlers/
│   │   ├── menu.py            # главное меню, визард и смена профилей
│   │   └── inline.py          # обработчик инлайн-запросов (@fz_arcotel_bot)
│   └── main.py                # запуск aiogram диспетчера
├── data/                      # локальные кэши и настройки пользователей
├── deploy/
│   ├── arcotel-bot.service    # systemd сервис для vps
│   └── deploy.sh              # скрипт автоматического обновления на сервере
├── tests/
│   └── test_flow.py           # сквозные тесты всех подсистем
├── requirements.txt           # python зависимости
├── .env.example               # пример конфигурации переменных окружения
└── .gitignore                 # исключения артефактов и секретов
```

### <img src="assets/icons/network.svg" width="22" height="22" valign="middle" /> развертывание и запуск на vps (msk)

деплой на сервер выполняется в одну команду:

```bash
./deploy/deploy.sh
```

скрипт автоматически переносит проект в `/opt/arcotel-schedule-bot`, собирает виртуальное окружение, ставит зависимости и регистрирует systemd-сервис.

управление службой на сервере:

```bash
# перезапуск службы
ssh msk "systemctl restart arcotel-bot.service"

# статус и журнал
ssh msk "systemctl status arcotel-bot.service"
ssh msk "journalctl -u arcotel-bot.service -f"
```
